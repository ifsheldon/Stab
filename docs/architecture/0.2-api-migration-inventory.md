# Stab 0.2 API Migration Inventory

> Historical ledger: this document records the incremental component extraction and temporary adapter decisions that preceded the final P2 facade reset. It is not a source-current API contract. Use [Migrating to Stab 0.2](../MIGRATING-0.2.md), [the component contracts](component-contracts.md), and the active [GOAL](../plans/GOAL.md).

This ledger accounts for public Rust API changes made between the frozen pre-0.2 baseline and the final Stab 0.2 component ownership model.

The left column preserves historical API names. The replacement and status columns describe the final P2 disposition, not an intermediate adapter checkpoint.

The final P2 reset removed the `advanced` and `experimental` facade tiers, the catch-all `CircuitError`, universal resource adapters, forwarding modules, duplicate capability descriptors, and execution compatibility adapters. Canonical low-level and extension APIs now use their owner crates directly.

## Status Values

- `migrated`: the old API has been removed or moved and its owner-crate replacement is implemented and tested. A `stab-core` root name is included only when it is a direct canonical type reexport.
- `pending`: the target replacement is specified but the old API remains current.
- `removed`: the old API had no useful supported replacement.
